# Clientibus

Lightweight CRM Application built with .NET, Windows Forms and EF Core.

## Overview
`Clientibus` is a Customer Relationship Management System (CRM) in development designed for small businesses to manage customer interactions,
track sales, and improve customer relationships. The application is built using .NET 8, Windows Forms for the user interface,
and Entity Framework Core for data access.

## Prerequisites
- .NET 8 SDK
- Visual Studio 2022 (or later) with .NET desktop development workload
